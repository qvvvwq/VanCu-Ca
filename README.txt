Vancouver 秋日旅行 App（GitHub Pages 版）
新增本機路線設定：
- 在「地圖與導航」輸入住宿地址並選擇開始／結束日期，按「套用日期與出發地址」。
- 指定日期範圍內每日交通連結會使用該地址作為 Google Maps 大眾運輸起點；10/30 抵達日仍從 YVR 出發，目的地使用你輸入的地址。
- 預設不保存地址。勾選「記住在這台裝置」才會存到目前瀏覽器 localStorage；「清除地址」可移除。
- 住宿街道地址不會寫入公開 HTML 原始碼。按 Google Maps 導航時，地址會隨導航請求傳給 Google。
更新時請將 index.html、assets/、Photo_Credits.txt 上傳到原本 GitHub repository 根目錄並覆蓋舊版。
地圖、天氣與遠端景點照片需要網路連線。
